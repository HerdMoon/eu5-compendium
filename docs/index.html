CH 02 人口、市场与财政

人口生态、迁移潮、疫病与三级粮食安全

人口是一切RGO产出、城市工匠、税收份额与征召兵的母池；粮食危机不仅饿死人口，更会瞬间抽干国家财政。

链路：地点等级、气候与河流 · 文化地位与宗教容忍 → 本章 → RGO与建筑就业填槽 · 征召兵永久人口代价

链路：地点人口与控制力 · 王室力量份额 → 本章 → 阶层金库与私有投资 · 思潮随商路跨海扩散
CH 04 政府、内阁与阶层

政府、官僚固化、人物互动与内阁 81 行动全景

内阁席位是治国最稀缺的生产力工具，官僚机构隐藏百年固化代价，而 34 项人物互动决定你是稳固继承还是陷入摄政危局。

链路：王室力量与各阶层力量 · 国家经济基础 → 本章 → 疆域整合与高控提速 · 灾后恢复与同化转正
CH 05 政府、内阁与阶层

阶层博弈、12 项直接互动、议会与叛乱检定

不仅要拆解「王室力量」的算法、特权的满意度公式与阶层私建偷钱，更要掌握 12 项主动互动键以及叛乱爆发瞬间的要塞守军倒戈检定。

链路：低控制未受控财富与人口 · 统治者 ADM 与集权价值观 → 本章 → 国家实收税率与贸易分成 · 陆海军征召兵供给闸门
CH 06 文化、信仰与科技

文化五态、四大语言、信仰与宗教修会

只有主流与已接纳文化计入 50% 核心门槛；礼仪语言直接驱动科研引擎；而跨国宗教修会依忠诚度可赐天佑亦可成沉重重担。

链路：DIP 内阁推广文化 / 宗教 · 市场中心主导市民人口 → 本章 → 核心化 50% 人口闸门 · 科研速率主驱动器

时代思潮、革新研发、殖民扩张与局势自动化

研发速度由礼仪语、识字率与教士决定；殖民必须由核心省供血人口；而开关错误的自动化常比操作失误更毁档。

链路：礼仪语力量、平均识字率、教士满意度 · 核心地点人口蓄水池 → 本章 → 跨时代新兵种与内阁席位上限 · 跨洋热带商品贸易帝国
